# Prompts for the four sessions

One file per person. Paste the whole file as the **first message** of a fresh
agent session (Claude Code, Codex, Cursor — whichever), rooted in the repo the
prompt names. Every prompt starts with the same preamble so the four sessions
share the same rules; the rest is that person's work, in order.

| File | Person | Repo |
|---|---|---|
| [`agent.md`](agent.md) | Agent owner | `majsq` |
| [`web.md`](web.md) | Web owner | `majsqweb` |
| [`bot.md`](bot.md) | Bot owner | `majsqbot` |
| [`festro-connect.md`](festro-connect.md) | Ali | Festro's private repos |

If a session proposes something that contradicts `DESIGN.md` or
`CONTRACT.md`, the doc wins. Tell the session so.
